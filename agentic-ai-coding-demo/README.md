# Agentic AI Coding Lab

Static demo app for exploring the agentic engineering workflow from the linked
skills repositories.

Open `index.html` in a browser. No build step is required.

## What It Demonstrates

- Small, reviewable feature loops.
- Source-code-as-context reference packs.
- Prompt construction with explicit rules and stop conditions.
- Code-structure cleanup as a separate pass after a feature works.
- Review feedback loops that converge toward a merge-ready state.
