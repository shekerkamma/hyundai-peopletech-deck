# Claude Code — Ruben Hassid (How to AI Substack)

## TL;DR
A beginner-friendly guide explaining how non-programmers can use Claude Code to build functional websites and apps through natural language prompts. Published March 19, 2026 on the "How to AI" Substack.

## Key Content

### Setup (4 Steps)
1. Create a GitHub account (free) to host code
2. Link GitHub to Claude via Settings > Connectors
3. Use English prompts — describe what you want, Claude builds it
4. Accept & iterate — approve changes, check live sites, request modifications

### Core Techniques
- **Screenshot-based prompting**: Paste images of desired designs and Claude recreates them
- **Outcome-focused briefs**: Describe results, not technical steps
- **File referencing**: Point Claude to existing project files for consistency
- **CLAUDE.md memory files**: Create project documentation so Claude remembers design choices across sessions
- **"Vibecoding" method**: Skip Permissions mode in VS Code eliminates repetitive approval popups

### Acknowledged Limitations
- Heavy token usage consumption
- Code quality requires testing rather than review
- Occasional infinite loops requiring manual intervention
- Generic default design choices without specific references
- Limited design sophistication without reference materials

## Key Takeaways
1. [[Claude Code]] is being positioned as a tool for non-technical users, not just developers
2. The CLAUDE.md file is the key persistence mechanism — it's the "memory" across sessions
3. Screenshot-based prompting is the most powerful technique for non-coders — show, don't describe
4. The honest limitation acknowledgments build credibility vs. hype-only posts

## Steal-Worthy Elements
- The 4-step setup structure makes complex tooling feel accessible
- "Vibecoding" as a named method gives the practice identity and shareability
- Pairing capabilities with limitations builds trust with the audience
