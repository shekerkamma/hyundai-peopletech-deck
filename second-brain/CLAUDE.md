# second-brain/ — Content research notes

Ingested research organized by source platform. These notes feed the deck-building
process but are never shown to customers directly.

## Conventions

- **One markdown file per source.** File name = slugified title or topic.
- **Notes are reference material, not deliverables.** Extract insights for decks
  but never copy-paste research framing into customer-facing slides.
- **Subdirectories are source platforms:** `github/`, `linkedin/`, `web/`, `youtube/`.
- **Internal tooling references stay here.** If a note mentions graphify, knowledge
  graphs, or other internal tools, that context is fine in research notes — just
  never surfaces in deck outputs.
